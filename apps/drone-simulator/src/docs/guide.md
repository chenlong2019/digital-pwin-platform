# 1. 启动与上手

最短的一条路径:

1. 打开页面 —— 自动上电,顶部状态条出现电量与阶段
2. 右侧「飞行」页 → **一键起飞**
3. 推摇杆飞
4. **智能返航** 或 **自动降落** 收尾

```bash
npm install
npm run dev
```

页面顶部显示会话标签与**确定性种子**。同种子 + 同操作序列 → 同结果,所以复现一次异常只需要记下种子和那串操作。

# 2. 电源与起飞

「飞行」页 → 电源 / 机械:

| 按钮 | 作用 |
| --- | --- |
| 开机自检 | 上电并跑自检(IMU / 指南针 / 定位 / Home 点) |
| 关机 | 断电,飞行中不可用 |
| 展开 / 收纳机臂 | 地面动作,飞行中被禁用 |
| 紧急停桨 | **只在地面可用**;空中调用会被内核拒绝并记一条警告 |

起飞前先看「遥测」页的**起飞检查单**:有阻塞项时「一键起飞」会保持禁用状态。

「飞行」组里还有 **智能返航** 与 **取消返航**。返航是两段式:先把机头原地对准返航点,对准之后才前进 —— 不会边飞边拐出一条弧线。

# 3. 飞行操作

## 摇杆台

常驻在视口正下方 —— 操纵和看画面是同一件事,不该藏进标签页。美国手 Mode 2:

| 杆 | 方向 | 通道 |
| --- | --- | --- |
| 左盘 | 上 / 下 | 升降 |
| 左盘 | 左 / 右 | 偏航(水平旋转) |
| 右盘 | 上 / 下 | 前后 |
| 右盘 | 左 / 右 | 横移 |

## 键位

| 键 | 动作 |
| --- | --- |
| `W` / `S` | 升降 |
| `A` / `D` | 偏航(水平旋转) |
| `↑` / `↓` | 前后 |
| `←` / `→` | 横移 |
| `Space` | 归中悬停 |

盘位与键位是**相加**后夹在 ±1 的,所以按住 `D` 再推满左盘也只是满舵、不会超调,两种输入在杆上互相可见。松手 / 松键即回中。

地面时摇杆禁用 —— 起飞后才生效。

## 挡位

平稳挡 C / 普通挡 N / 运动挡 S,影响最大速度与加速度。

# 4. 视角与相机

## 三个视角

| 视角 | 说明 |
| --- | --- |
| 观察者 | 轨道相机,鼠标拖拽绕机旋转、滚轮缩放 |
| 跟随 | 跟在机后,随航向转 |
| 机载 | 第一人称,画面即云台相机所见 |

视口右上角可以直接切,「飞行」页的视角组里也有。

**变焦只在机载视角生效** —— 切回观察者时,你原来那一档滚轮缩放会被还回来,不会被相机的变焦覆盖掉。

## 云台

「相机」页:俯仰滑杆,外加 **回中** / **垂直向下** / **水平前视** 三个预设。

## 拍照与录像

- **拍照** 出 PNG,**云台取景**(与机载视角同一构图,含变焦)
- **录像** 出 WebM,**同样是云台取景** —— 所以你在观察者视角绕飞机运镜,录出来的也是机头视角的画面

文件生成后自动下载;若浏览器把自动下载拦了(没有用户手势时可能发生),面板上会留一个手动下载入口。另外,自动降落或返航落地收尾时领域层会主动停录,成片照常落盘。

# 5. 感知

## 测距雷达

| 项 | 说明 |
| --- | --- |
| 镜头瞄准 | 「正前 / 正上」与「镜头朝向」两种判读基准 |
| 前视双镜头 | 左右各一个,判读时取更近的那个当正前方 |
| 上视双孔 | 向上测障碍 |
| 可视化 | 雷达锥与辅助光束可分别开关 |

## 灯光系统

| 灯 | 说明 |
| --- | --- |
| 尾部状态灯 | 默认跟随飞行状态;也可手动锁定某一条灯语 |
| 电量指示灯 | 真机四格灯的手册编排,可选不同显示模式 |
| 底部辅助灯 | 真机在地面锁定(避免起降刺眼),起飞后才亮 |

灯语是**产品行为**,判定在领域层、渲染层只查表 —— 所以界面上看到的灯语含义和真机手册一致。光束锥只影响画面,不影响照明。

# 6. 航点任务

「任务」页:先看航点清单,再 **创建航点任务** → **启动**,过程中可 **暂停** / **继续** / **中止**。

任务阶段依次为 `待命 → 起飞 → 巡航 → 悬停 → 降落 → 完成`。

两个容易踩的点已经处理掉了:每个航点先爬升到航段高度再平移(不是斜着插过去);雷达探到前方障碍会自动抬升绕行;到达判据用的是**实际高度**的容差,而不是标称高度。

# 7. 场景与环境

| 项 | 说明 |
| --- | --- |
| 时间倍率 | 仿真时间的推进速度,不影响物理步长 |
| 风速 / 风向 | 机体感受到的是相对风 |
| 天气 | 切换后影响画面与能见度 |
| 可视化 | 障碍物 / 坐标轴 / 导线的开关（场景里没有导线时导线那项不出现） |
| 场景信息 | 标识、确定性种子、障碍物数、导线数、电子围栏范围 |
| 模型部件 | GLB 部件自检,缺件会列出来 |

场景是**只读**的:当前版本没有「运行中换场景」的入口,换场景要重建会话。天气、风、时间倍率这些环境参数则可以随时热改。

# 8. 遥测与日志

**状态条**(常驻)显示电量、相对高度、水平速度、阶段、任务 —— 切到哪个标签页都能余光扫到。

**遥测页**给更细的:电池与电量模式、关键读数、起飞检查单、告警、任务进度。

**日志页**把事件流和指令流分开记。每个按钮都等于一条 Command,命令是被接受还是被拒绝,这里看得到。

# 9. 电网巡检

左上角 **电网巡检** 进入 `/grid`。这一页不手动飞 —— 作业由任务自己完成，
人做的是**定方案**与**看结论**。

## 作业流程

1. **定方案**：「巡检」页里调镜头倍率与单拍点采集时长。改完航线当场重算，
   「拍点 / 部位」「转场里程」跟着变 —— 拍点数是推导出来的，不是写死的。
2. **创建并启动巡检**：任务先等机体上电就绪，再自动起飞、爬到巡检高度、逐塔转场 → 转机身 → 悬停采集 → 落地。
   过程中可 **暂停** / **继续** / **中止**。方案在任务进行中会锁定。
   点得快也不要紧：机体还没上电、或自检 / 预热还没走完时，任务会停在「等待机体就绪」
   并自己重试起飞指令，不会因为「启动太早」而失败。
3. **看进度**：面板里能看到当前阶段（含第几拍点 / 共几拍点）、拍点进度条，
   以及**载荷瞄准**读数 —— 云台在瞄哪个部位、距离多少、残余误差多少。
4. **看结论**：「报告」页随采集逐条长出来，巡检没跑完也能看（状态标成「巡检中」）。
5. **导出**：JSON / CSV / Markdown。导出的是**此刻**的报告，时间戳是现取的。

## 判据怎么来的

每个部位按「拍摄配方」分组（同一方位、同一距离共用一次悬停）：一基塔 11 个检查部位
（塔头 1 + 横担 4 + 绝缘子 4 + 塔身 1 + 塔基 1）合并成 4 个拍点，六基塔共 24 个拍点。
采集时按**实际位姿**算成像质量：特征落在几个像素上、偏心多少、俯仰多少、机身偏差多少
—— 云台偏航行程只有 ±5°，超出部分要靠转机身补，这正是「先转机身再拍」这一步存在的原因。

判定结果分四类：**正常 / 疑似 / 缺陷 / 未采集**。成像质量低时最强也只能给「疑似」，
因为它能给的最诚实结论就是「回去复拍」。

## 报告里那块黄色的「仅用于对账」

巡检报告分两块：上面是**巡检结论**（现场能拿到的），下面是与**地面真值**的对账
（命中 / 漏检 / 误报 / 召回 / 精度）。真值是仿真世界写在杆塔资产上的事实，
现场拿不到 —— 所以它单独成块并明确标注，避免让人以为现场也能这么统计。

召回 / 精度在分母为零时显示「—」，不假装 100%。

## 作业评价：这份活干得怎么样

「报告」页里还有一块**作业评价**，它把报告读数压成四条指标：**部位覆盖率 / 缺陷
召回率 / 报警精度 / 平均成像质量**。每一项对着一条达标线算分（刚好达标 = 满分），
四项按「后果有多贵」加权 —— 覆盖率与召回率权重最高，因为漏检会倒塔、少拍会漏隐患。

评分旁边是**违规清单**，轻重分四档：漏检是「严重」，覆盖缺口按缺口大小分档，
画质不足与误报偏多是「轻微」，机位俯仰超限这类提醒是「提示」。
**只有「严重」以上的才判「不通过」**。

**巡检没跑完时状态是「未完成」，不是「不通过」** —— 没跑完和跑得差是两件事。
同理，四条指标里哪一条没有数（例如这次没遇到真值缺陷，召回率是「—」），它就不参与
评分、分母按参与项重算：**「不知道」既不算 0 分，也不算满分**。

## 一键复现

同一条线路、同一份方案、同一个种子 ⇒ 同一次巡检得到同一份报告。换种子才会变。

# 10. 常见问题

**推摇杆没反应** —— 大概率还没起飞。摇杆在地面是禁用的。

**「一键起飞」是灰的** —— 没上电,或起飞检查单里有阻塞项(去「遥测」页看是哪一条)。

**巡检/航点任务停在「等待机体就绪」** —— 页面刚打开,机体还在自检 / 预热 / 搜星。
任务会自己重试起飞指令,不用重新点。一直停着的话,去「遥测」页看起飞检查单卡在哪一项。

**变焦没效果** —— 变焦只在机载视角生效。

**录像没保存** —— 先看面板上的提示;如果是浏览器拦了自动下载,用手动下载入口。

**「紧急停桨」是灰的** —— 设计如此,空中禁用(空中停桨会坠机)。

**视口提示渲染降级** —— 仿真是独立于渲染的:数据面板、指令下发与任务执行在渲染失败时照常工作,刷新页面即可重试。

**「创建并启动巡检」是灰的** —— 飞行器已在空中,或上一次巡检任务还没收尾。先让飞机落地或中止任务。

**镜头倍率 / 采集时长拖不动了** —— 巡检进行中方案会锁定(改了会让界面与任务手里的航线对不上)。中止后即可再调。

**报告里的召回率是「—」** —— 这次巡检没有遇到任何真值缺陷,分母为零。这种情况谈召回率没有意义,所以不给数字。

**第二次巡检的进度条不动** —— 不会出现:每次「创建并启动」都创建一个新任务并把它设为当前任务。若真遇到,去「日志」页看任务创建事件。
