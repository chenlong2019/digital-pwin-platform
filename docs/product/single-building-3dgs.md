# 单栋楼精细重建

先集中验证园区西南侧的独立楼 A：平台坐标 X=-117..-91m、Z=-46..-14m，楼顶约 35.64m。整园区实验及其报告保留，单栋任务使用独立场景、数据集和模型。

## 固定数据源

`scripts/prepare-building-scene.mjs` 只读 points-viewer 的独立 LOD0 文件，从原始量化坐标裁剪，不使用共享 pack 偏移。墙面保留 LOD0；低于 0.4m 的水平地面每 0.25m XZ 格保留首点。导出的 479,129 点资产约 2.44MiB，可随仓库运行。

```powershell
node scripts/prepare-building-scene.mjs D:/cpp-projects/points-viewer/public/data/campus-road-v2
```

输出在 `apps/drone-simulator/public/scenes/campus-building-a/`：`index.json`、`overview.bin.gz` 和 `provenance.json`。来源清单记录原索引哈希、每块源文件哈希、来源 LOD、点数、裁剪规则和坐标范围。浏览器与训练读取同一个固定资产，并核对索引与解压数据哈希。

单栋采集将源点绘制为直径 1.7 倍采样间距的重叠不透明圆片，并取消球面点光照，以减少墙面点间空隙。使用原始 RGB，没有添加照片、锐化或新纹理。该表示写入数据集 `metadata.pointAppearance` 和报告 `capture_representation`，不应将它与旧版球面圆点的像素指标直接比较。旧园区仍使用原有显示方式。

## 采集和训练

实验页默认提供“单栋精细”档：真实输出 1024×768 PNG、像素匹配的相机内参，64 个训练视角和 8 个预先固定的独立测试视角。训练包含半径 46m 的三个高度环，以及半径 34m 的近景细节环；近景允许裁切部分楼体。测试使用不同角度、高度与半径，不进入训练或参数选择。

```powershell
node scripts/run-campus-experiment.mjs --preset=building --steps=4000
```

`building` 训练配置独立版本化：0.22m 体素初始化，最多 180,000 高斯，局部 PCA 估计墙面/屋面法线，将可信表面的高斯压扁；法线方向初始 sigma=0.022m，切线方向 sigma=0.121m。归一化中心为 [-104,18,-30]m、尺度 40m。尺度允许 0.015..0.45m，不复用覆盖整园区的大尺度高斯。

采用现有 L1+DSSIM 优化几何、颜色、旋转、尺度和透明度。高分辨率参考图保留在 CPU，每步只上传所选图块；配置支持按图块累积梯度以限制显存。当前仍为固定高斯数量、degree-0 颜色，没有自适应增密或 CUDA 专用光栅器。

断点仍保存模型、Adam、初始模型、CPU/CUDA RNG、数据与来源哈希、配置及累计时间；恢复要求相同数据和训练配置。小型 CPU 数值测试覆盖表面初始化后恢复与连续训练的模型、Adam 状态、RNG 完全一致。

## 查看和评价

报告与 Three.js 查看器沿用实验页入口。Three.js 直接读取训练导出的标准高斯 PLY，可环绕、缩放、俯视及切换测试相机。相机自动按单栋模型范围取景。

独立报告保存 8 个测试视角的参考图、预测图、误差图，以及 PSNR、SSIM、前景 PSNR、同步后的 Torch 渲染耗时。浏览器帧率和 Torch 后端帧率分别标注。不同场景、源点精度、显示方式或相机下的指标不能视为同口径提升。

2026-11-06 本机实跑：`job-c28661224a6d`，数据集 `campus-1793970483797`，实际 161,497 个高斯，其中 97,147 个使用表面初始化，训练 4,000 步、582.49 秒。所有指标使用这次预先固定的 8 个测试视角：

| 同一数据与相机 | 初始化 | 训练后 |
| --- | ---: | ---: |
| PSNR | 22.52 dB | 26.46 dB |
| SSIM | 0.8859 | 0.9332 |

训练后前景 PSNR=23.31dB，前景平均占比 28.34%。1024×768 下 Torch 参考后端同步渲染约 1.19FPS，平均 837.60ms，P95=931.89ms。Three.js 的独立交互检查已通过旋转、缩放、俯视、环绕、8 个测试相机、刷新、窄屏和卸载检查；浏览器交互帧率与 Torch 后端分别计量。

本机查看：[实验结果](http://127.0.0.1:45679/experiments?job=job-c28661224a6d)、[Three.js 模型](http://127.0.0.1:45679/experiments/job-c28661224a6d/model)。这些数据保存在本机服务的数据目录中，Git 仓库包含源场景、实现与复现脚本；其他机器需重新运行采集训练。

本次验证通过架构、类型与构建检查、24 个服务测试、17 个算法数值测试和 13 个实验/模型浏览器测试。算法测试包含表面法线、非等长图块分批梯度一致性，以及断点恢复后模型、Adam 和 RNG 与连续训练完全一致。

数据仍是包含合成立面的点云，使用已知几何、颜色和相机位姿；只能验证这一仿真场景的成像与高斯拟合能力，不能恢复原数据不存在的照片纹理。这些相机轨迹用于采集图像，尚未验证无人机航线可飞性。
