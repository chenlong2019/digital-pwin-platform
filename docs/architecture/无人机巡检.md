# 2. 依赖方向总原则

整个项目统一遵循：

```text
Application
    ↓
Domain API
    ↓
Business Capability
    ↓
Domain
    ↓
Core
    ↓
Contracts
```

具体：

```text
                    ┌──────────────────┐
                    │ drone-inspection │
                    │      app         │
                    └────────┬─────────┘
                             ↓
                    ┌──────────────────┐
                    │    domain-api    │
                    └────────┬─────────┘
                             ↓
        ┌────────────────────┼─────────────────────┐
        ↓                    ↓                     ↓
 power-mission       power-evaluation          scenario-core
        ↓                    ↓
 power-domain       evaluation-core
        ↓                    ↓
    task-core               result
        ↓
 simulation-core
        ↓
  agent-core / sandbox-core
        ↓
    contracts
```

Renderer 是边缘 Adapter：

```text
SimulationSnapshot
        ↓
  three-adapter
        ↓
      Three.js
```

---

# 3. import/export 的总红线

## 允许

```text
Higher Layer
   ↓
Lower Layer
```

## 禁止

```text
Lower Layer
   ↓
Higher Layer
```

因此禁止：

```text
contracts → simulation-core
simulation-core → power-mission
agent-core → drone-inspection
power-domain → drone-agent
recorder → power-mission
three-adapter → simulation internals
```

## 4.1 common/ids.ts

职责：

```ts
export type ID = string
export type SessionId = ID
export type AgentId = ID
export type TaskId = ID
export type CommandId = ID
export type EventId = ID
```

不允许 import 任何业务包。

---

## 4.2 common/vector.ts

定义平台公共数学契约。

```ts
export interface Vector3 {
  readonly x: number
  readonly y: number
  readonly z: number
}
```

注意：

> V1 不建议直接把 `THREE.Vector3` 放进 contracts。

这样以后换 Cesium、Babylon、原生数学库时不会污染 Core。

## 4.3 agent/agent.ts

```ts
export interface Agent {
```

## 4.4 command/command.ts

```ts
export interface Command<TType extends string = string, TPayload = unknown> {
  readonly commandId: CommandId
  readonly type: TType

  readonly sessionId: SessionId
  readonly actorId: ID

  readonly agentId?: AgentId
  readonly taskId?: TaskId

  readonly timestamp: number
  readonly payload: TPayload
}
```

## 4.5 event/event.ts

```ts
export interface Event<TType extends string = string, TPayload = unknown> {
  readonly eventId: EventId
  readonly type: TType

  readonly sessionId: SessionId
  readonly agentId?: AgentId
  readonly taskId?: TaskId
  readonly actorId?: ID

  readonly tick: number
  readonly timestamp: number

  readonly payload: TPayload
}
```

# 42. 为什么 safety 暂时放 power-mission

因为 V1 的安全需求明显与业务任务绑定：

```text
Minimum Distance to PowerLine
PowerTower Collision
Power Inspection Geofence
```

现在没必要为了“未来可能复用”马上抽成：

```text
safety-core
```

等 Vehicle / Robot 真的出现共同规则，再提取。

# 107. Circular Dependency 检查

必须禁止：

```text

```

特别关注：

```text

simulation-core ↔ drone-agent
power-mission ↔ power-evaluation
result ↔ power-evaluation
recorder ↔ replay
domain-api ↔ application
```

```text

```

正确：

```text
power-mission
      ↓
power-evaluation
```

但 `power-mission` 绝对不要 import：

```text
InspectionPointResult
```

这样的评价模型。
